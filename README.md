# 김장하기 게임

김장 과정을 7단계(배추 뽑기 → 자르기 → 소금에 절이기 → 씻기 → 양념 만들기 → 버무리기 → 장독에 담기)로 직접 해 보는 터치 게임입니다.

- 전자칠판·태블릿·PC 터치/마우스 지원 (화면 크기에 자동 맞춤, 전체 화면 버튼)
- 단계별 음성 안내(신경망 음성 녹음 mp3, 실패 시 Chrome 한국어 음성)
- 씻기·버무리기 등 동작별 효과음(Web Audio 합성)
- 20초 동안 조작이 없으면 안내 음성과 손가락 힌트를 다시 보여 줌
